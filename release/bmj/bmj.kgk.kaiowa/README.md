Kaiowá lexical model
====================

Copyright (C) 2026 Bruno Maia de Jesus - TJ

Version 1.0

Description
-----------
Word suggestions and corrections for Kaiowá (`kgk`), for the Kaiowá keyboard. Search ignores diacritics
and apostrophes, so the user does not need to type tildes or accents to find a word.

Sugestões de palavras em kaiowá, para o teclado Kaiowá.

Sources
-------
3097 words with frequencies from the official Kaiowá translations of the programme "Língua Indígena Viva no Direito" (AGU, Ministry of Indigenous Peoples, Ministry of Justice, IDGlobal): the 1988 Brazilian Constitution, ILO Convention 169 and the SDGs, plus the Portuguese–Kaiowá legal glossary. Official acts are not protected by copyright in Brazil
(Law 9,610/98, art. 8). Portuguese words were filtered out by letters not used in Kaiowá and by a Brazilian
Portuguese frequency list; PDF substitutes were normalized (’ ´ ʼ → ', ī ē ū → ĩ ẽ ũ).
