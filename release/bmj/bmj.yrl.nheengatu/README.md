Nheengatu lexical model
=======================

Copyright (C) 2026 Bruno Maia de Jesus - TJ

Version 1.0

Description
-----------
Word suggestions and corrections for Nheengatu (`yrl`), for the Nheengatu keyboard. Search ignores diacritics
and apostrophes, so the user does not need to type tildes or accents to find a word.

Sugestões de palavras em nheengatu, para o teclado Nheengatu.

Sources
-------
2593 words with frequencies from the official translation of the 1988 Brazilian Constitution into Nheengatu (National Council of Justice and Supreme Federal Court, 2023). Official acts are not protected by copyright in Brazil
(Law 9,610/98, art. 8). Portuguese words were filtered out by letters not used in Nheengatu and by a Brazilian
Portuguese frequency list; PDF substitutes were normalized (Greek ῖ and ī → ĩ, ē → ẽ, ū and ữ → ũ).
